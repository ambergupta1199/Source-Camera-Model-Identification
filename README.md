# 📸 Source Camera Model Identification (SCMI)

Source Camera Model Identification (SCMI) is a task in **digital image forensics** that aims to determine the **camera model** used to capture an image. This project provides tools, preprocessing scripts, and machine learning/deep learning models for SCMI research and applications.

---

## 🔍 Features
- Extracts **camera-specific artifacts** (sensor noise patterns, CFA interpolation traces, etc.)
- Supports **benchmark datasets** (Dresden, VISION, SOCRatES, etc.)
- Machine Learning and Deep Learning models for classification
- Preprocessing utilities for image patches and noise residual estimation
- Training and evaluation pipelines

---

## ⚙️ Tech Stack
- **Language:** Python  
- **Libraries:** NumPy, OpenCV, scikit-learn, PyTorch/TensorFlow  
- **Tools:** Jupyter Notebook
